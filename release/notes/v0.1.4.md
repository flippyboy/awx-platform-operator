# awx-platform-operator v0.1.4

## Fix: JWT controller service secret generation (kubectl missing)

Gateway reconcile failed with:

```text
kubectl: command not found
```

when creating `{gateway}-controller-service-secret`. That left
`AWX.spec.gateway_service_secret_secret` empty and Jewel reported Controller
unavailable after the Service-port fix.

### Changes

- Generate the JWT secret with `kubernetes.core.k8s_exec` + `k8s` (no kubectl)
- Always set `gateway_service_secret_secret` on the platform child AWX CR to the
  well-known secret name so the installer remounts once the secret exists
- Status patch no longer shells out to kubectl

### Helm / GitOps

Still set under `AWXPlatform.spec.gateway`:

```yaml
controller_service_port: "80"
controller_service_https: false
```
