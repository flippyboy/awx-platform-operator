# awx-platform-operator v0.1.8

## Fix: more unquoted Jinja in AWXPlatform role

Playbook failed YAML parse on:

```yaml
create_certificate: {{ gateway.create_certificate | default(true) | bool | lower }}
```

`default(true)` is invalid YAML before Jinja runs. All boolean fields in the
child CR definitions are now quoted.
