# awx-platform-operator v0.1.0

Initial public scaffold of the **platform operator** for modern AWX (Controller + Jewel gateway + Envoy).

## What's included

- Operator roles evolved from [ansible/awx-operator](https://github.com/ansible/awx-operator):
  - **Phase 1** gateway consumer fields on `AWX` (`gateway_url`, service secret, open-source license defaults)
  - **`AWXGateway`** role: Jewel + Redis (managed or external) + Envoy + trust/register job
  - **`AWXPlatform`** role: child CRs, external Postgres wiring, optional Ingress → Envoy
- Helm chart `charts/awx-platform-operator` (fork of ansible-community/awx-operator-helm)
  - CRDs: AWX, AWXGateway, AWXPlatform, Backup, Restore, MeshIngress
  - External Postgres / Redis secrets
- Kind smoke scripts under `hack/scripts`
- CI: Helm lint/template; release workflow for image + chart package

## Component images

Built and released by sibling repo [awx-platform-images](https://github.com/flippyboy/awx-platform-images).  
See `release/pins.consumer.yaml` for default registry paths under `ghcr.io/flippyboy/…`.

## Install

```bash
helm upgrade --install awx-platform oci://ghcr.io/flippyboy/charts/awx-platform-operator \
  --version 0.1.0 -n awx-platform --create-namespace
# or from the packaged .tgz attached to this release
```

Until a multi-arch operator image is fully validated in your cluster, kind users can still reconcile with:

```bash
./hack/scripts/kind-up.sh
./hack/scripts/kind-reconcile-gateway.sh
./hack/scripts/kind-reconcile-controller.sh
```
