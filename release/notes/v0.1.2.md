## Highlights

### Shared Jewel + Envoy TLS via cert-manager

- Default: operator creates namespaced **self-signed Issuer** + **Certificate**
- Resulting Secret `{gateway}-tls` is mounted into **both** Jewel and Envoy
- ConfigMap `{gateway}-tls-ca` published for **Gateway API BackendTLSPolicy**
- Legacy init-generated emptyDir PEMs remain when `create_certificate: false` and no `tls_secret`
- Operator Role includes `cert-manager.io` certificates/issuers verbs

### CR / Helm knobs

```yaml
AWXGateway:
  spec:
    create_certificate: true
    create_tls_issuer: true
    # tls_secret: optional override
    # tls_dns_names: [awx.example.com]
    create_tls_ca_configmap: true
```

Also on `AWXPlatform.spec.gateway.*`.

### Install

```bash
# cert-manager required for default TLS path
kubectl apply -f https://github.com/cert-manager/cert-manager/releases/download/v1.16.2/cert-manager.yaml

helm upgrade --install awx-platform oci://ghcr.io/flippyboy/awx/awx-platform-operator-helm \
  --version 0.1.2 -n awx-platform --create-namespace
```

See `charts/awx-platform-operator/examples/backend-tls-policy.yaml`.
