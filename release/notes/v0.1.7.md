# awx-platform-operator v0.1.7

## Fix: AWXPlatform playbook YAML parse error

Reconcile failed before any children were applied:

```text
roles/platform/tasks/main.yml: tls_dns_names: {{ gateway.tls_dns_names | default([]) | to_json }}
did not find expected ',' or '}'
```

Ansible parses the task file as YAML *before* Jinja, so unquoted `[]` broke the playbook.
Quoted the expression.
