# awx-platform-operator v0.1.6

## Better defaults for a new platform install

A working stack should only need:

```yaml
AWXPlatform:
  enabled: true
  name: awx
  spec:
    admin_password_secret: <existing-secret>        # optional; auto-created if omitted
    postgres_configuration_secret: <existing-secret>
```

Chart / operator now default to:

| Component | Default |
|-----------|---------|
| Operator image | `ghcr.io/flippyboy/awx/awx-platform-operator` (chart tag) |
| Controller | `ghcr.io/ansible/awx:devel` |
| Gateway | `ghcr.io/flippyboy/awx/jewel-with-ui:0.1.0` |
| Gateway TLS | cert-manager Certificate + Issuer |
| Jewel → Controller | Service port **80**, HTTP |

Site GitOps no longer needs to repeat those knobs.
