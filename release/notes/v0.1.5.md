# awx-platform-operator v0.1.5

## Fix: JWT secret Job (no kubectl, no k8s_exec)

0.1.4 used `k8s_exec` into the Jewel container; that failed with OCI exec errors
and left `gateway_service_secret_secret` empty (Jewel 503 / controller unavailable).

This release mints the secret with a **Job** using the Jewel image and the
in-cluster Kubernetes API (dedicated SA + Role).

Also saved: `docs/go-operator-assessment.md` (later greenfield Go operator).
