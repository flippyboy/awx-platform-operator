# awx-platform-operator v0.1.3

## Fix: Jewel → Controller service port

AWXPlatform was registering the controller on **container port 8052**, but the
installer Service only exposes **port 80** (`targetPort: 8052`). Envoy/Jewel
therefore could not reach the controller API.

### Changes

- Platform child AWXGateway defaults `controller_service_port: "80"`
- Gateway role default `controller_service_port: "80"`
- Trust register job `ensure()` **PATCHes** mismatched fields (service_port, address)
- kind scripts aligned to port 80

### Verify

```bash
# Child CR
kubectl get awxgateway -o jsonpath='{.items[0].spec.controller_service_port}{"\n"}'
# Should be 80

# From a pod in the same namespace:
curl -sS -o /dev/null -w '%{http_code}\n' http://<awx>-service:80/api/
# 401/302/200 OK — not connection refused
```
